# ClaudeNotify

A macOS menu bar app that tells you what your [Claude Code](https://claude.com/claude-code) sessions are doing — working, waiting on background tasks, done, or needing your attention — with Mac notifications and optional phone pushes via [ntfy](https://ntfy.sh).

> **Unofficial.** ClaudeNotify is an independent, community project. It is not affiliated with, endorsed by, or sponsored by Anthropic, PBC. "Claude" and "Claude Code" are trademarks of Anthropic, PBC, used here only to describe what this app works with.

## Features

- Menu bar bell showing overall status ("2 working", "my-project needs you", "✓ Done")
- Per-session list with elapsed time, last message, and a recent-events log
- Mac notifications with configurable sounds per event type
- Optional phone pushes via ntfy (deliberately generic — no project names, paths, or message text leave your Mac)
- Mute for 1 h / 4 h / until tomorrow, launch at login

Requires **macOS 15 (Sequoia) or later**.

## Install

### Option 1 — one-line installer (recommended)

```bash
curl -fsSL https://raw.githubusercontent.com/lhegstrom/ClaudeNotify/main/install.sh | bash
```

Installs the app to `~/Applications`, sets up the Claude Code hooks, and launches it.

### Option 2 — Homebrew

```bash
brew install --cask lhegstrom/tap/claudenotify
open /Applications/ClaudeNotify.app
```

This taps [lhegstrom/homebrew-tap](https://github.com/lhegstrom/homebrew-tap) and trusts just this cask (Homebrew 6.0+ requires trust for non-official taps). The app sets up the Claude Code hooks the first time it opens. After that, `brew upgrade claudenotify` and `brew uninstall claudenotify` work by the short name.

### Option 3 — manual download

Download `ClaudeNotify.zip` from [Releases](https://github.com/lhegstrom/ClaudeNotify/releases/latest), unzip, and drag `ClaudeNotify.app` to Applications.

Because the app isn't notarized by Apple (that requires a paid developer account), macOS will block the first launch. Either:

- open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**, or
- run `xattr -dr com.apple.quarantine /Applications/ClaudeNotify.app`

On first launch the app sets up the Claude Code hooks (or click **Install** in its panel if you see a warning).

### Option 4 — build from source

Requires Xcode or the Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/lhegstrom/ClaudeNotify.git
cd ClaudeNotify
./build.sh
```

## How it works

ClaudeNotify uses [Claude Code hooks](https://docs.claude.com/en/docs/claude-code/hooks). The installer:

1. copies `hooks/notify.sh` to `~/.claude/hooks/notify.sh`
2. adds entries for `Stop`, `Notification`, `UserPromptSubmit`, `SessionEnd`, and `PostToolUse` to `~/.claude/settings.json` (existing hooks are kept; a backup is saved as `settings.json.bak-claudenotify`)

The hook appends events to `~/.claude/notify/events.jsonl`, which the app watches. Settings live in `~/.claude/notify/config.json` and can be edited from the app.

New Claude Code sessions pick up the hooks automatically; restart any sessions that were already running.

## Phone notifications

Install the ntfy app ([iOS](https://apps.apple.com/app/ntfy/id1625396347) / [Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy)), subscribe to a hard-to-guess topic name, and enter the same topic in ClaudeNotify's panel. Anyone who knows the topic can read it, which is why pushes contain only "Task complete" / "Needs your attention".

## Uninstall

1. In the app: gear menu → **Remove Claude Code hooks** (or run `~/Applications/ClaudeNotify.app/Contents/Resources/install-hooks.sh --uninstall`)
2. Quit the app and delete it — or `brew uninstall --cask claudenotify` (add `--zap` to also delete settings and history)
3. Optionally delete `~/.claude/notify/`

## Releasing (maintainers)

```bash
scripts/release.sh 1.1.0     # bumps VERSION, builds dist/ClaudeNotify.zip, updates the cask in ../homebrew-tap
# then follow the printed commit / tag / `gh release create` / tap push commands
```

Expects a checkout of [lhegstrom/homebrew-tap](https://github.com/lhegstrom/homebrew-tap) next to this repo (or set `TAP_DIR`). The release asset must be named `ClaudeNotify.zip` — the installer and cask both depend on it.
